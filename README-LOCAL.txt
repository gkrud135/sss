BLUE LAB - Local UI editing

1. Extract the entire blue folder.
2. Install Node.js if it is not already installed.
3. Open a terminal in the blue folder and run: npm start
4. Open http://127.0.0.1:5173 in a browser.
5. Edit index.html (structure), styles.css (appearance), app.mjs (UI behavior), then refresh.

No npm install is needed. ES modules and JSON data require a local HTTP server; opening index.html directly is insufficient.
Student images are referenced from Schale DB and need an internet connection.
Run npm test for calculator tests. The Python data sync script is included.
Cloud deployment credentials/configuration and preview screenshots are not included.
