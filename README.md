# BLUE LAB

블루아카이브 한국·글로벌 출시 학생의 육성과 팀 편성, 시간에 따른 피해와 코스트를 계산하는 비공식 팬 웹사이트입니다.

## 실행

Node.js가 있는 환경에서 `npm start` 후 http://127.0.0.1:5173 에 접속합니다. 패키지 설치와 빌드 과정은 없습니다. `BLUE_LAB_PORT`로 다른 포트를 지정할 수 있으며 서버는 로컬에만 바인딩합니다.

## 임시 배포

[Firebase 임시 사이트](https://blue-lab-preview-261002-6b71--preview-fg2lh88c.web.app)는 **2026년 10월 9일 19:43 (한국 시간)**에 만료됩니다. 기존 Google 계정의 별도 프로젝트 `blue-lab-preview-261002-6b71`에 배포했습니다. 결제 계정을 연결하지 않은 정적 호스팅입니다. 만료 후 미리보기 채널은 삭제되고 프로젝트는 남습니다.

```powershell
python scripts/deploy-preview.py --project blue-lab-preview-261002-6b71
```

동일 채널을 갱신하며 만료 시각을 연장하지 않습니다. 배포 스크립트는 공개 앱 파일 15개만 허용하고, 인증 토큰은 기존 Google Cloud SDK 로그인에서 받아 메모리에서만 사용합니다. 인증 정보·스크립트·테스트는 업로드하지 않습니다. 공개 파일 해시와 배포 정보는 `deployment.json`에 기록합니다.

## 사용

상단 메뉴는 **학생·편성 / 택틱** 두 화면입니다. 탭을 오가도 입력과 계산 결과는 유지됩니다.

**학생·편성** 화면은 왼쪽 학생 목록, 위쪽 팀 편성 칸, 아래쪽 육성·능력치·스킬·계산 결과로 이루어집니다.

- 검색창 하나로 학생 이름과 스킬 이름·설명을 함께 찾습니다. 필터 버튼을 열면 출시 서버, 학원, 공격 타입, 스킬 종류·효과·대상으로 좁힐 수 있고, 적용 중인 필터 수가 버튼에 표시됩니다. 검색 결과는 스킬 보유 여부이며 시뮬레이터의 자동 지원 여부와 별개입니다. 애용품·고유무기 강화 스킬도 검색하며 해당 조건을 결과에 표시합니다.
- 팀 칸의 학생을 누르면 그 학생의 육성을 조절합니다. 빈 칸을 누르면 칸이 선택되고, 이어서 목록에서 학생을 누르면 바로 편성됩니다.
- 학생 소개 영역의 버튼 하나가 상황에 따라 **편성**(빈 칸), **교체**(채워진 칸), **편성 해제**(이미 편성된 학생)로 바뀝니다. 옆의 선택창으로 칸을 정합니다.
- 편성 목록은 전투 콘텐츠별로 보관되며 팀 칸 위의 표시가 어느 콘텐츠의 편성인지 알려 줍니다.
- 계산 결과는 택틱 화면의 전투 조건을 대상으로 합니다. 결과 상단에 대상 적(콘텐츠, 보스, 난이도, 방어 타입, 전장, 레벨, 방어력, 적용 중인 보정 수)을 표시하고, 옆의 버튼으로 전투 조건을 바꾸러 갈 수 있습니다.

**택틱** 화면은 위쪽에서 총력전·대결전·종합전술시험·직접 입력을 고르고, 왼쪽에 설정, 오른쪽에 작전 보드를 둡니다. 설정은 전투 조건, 보정 수치, 실행 설정, 보스 패턴, 보스 페이즈, 자동 공격 주기, 시작 EX 순서로 나뉘며 접고 펼 수 있습니다.

1. 기본 예시 파티에서 시작합니다. 학생·편성 화면에서 스트라이커 4명·스페셜 2명을 바꿉니다.
2. 전투 조건에서 보스, 난이도, 전장, 방어 타입을 선택합니다. 직접 입력도 가능합니다.
3. 작전 보드의 EX 카드를 누르면 시간 선에 순서대로 놓입니다. 지금 손패인 카드 3장만 밝게 표시되고, 나머지는 대기 또는 전투 불능 표시와 함께 비활성화됩니다. 서로 겹치는 카드는 두 줄로 나뉘어 놓이며, 재생 중에는 시간 선이 재생 위치를 따라 움직입니다. 빈 시간 선을 눌러 배치 위치를 바꾸거나 놓은 카드를 끌어 옮기고, 좌우 키로 0.1초씩 이동할 수 있습니다. 코스트가 충족되고 학생이 행동할 수 있는 시각으로 맞춰집니다. 초기 코스트와 제한 시간은 실행 설정에서 정합니다. 선택한 카드의 대상·세부 효과는 보드 아래에서 조정합니다.
4. 설정을 바꾸면 자동으로 다시 계산됩니다. 재생 버튼 하나가 필요하면 먼저 계산한 뒤 재생과 일시정지를 오갑니다. 코스트 게이지, 선택한 카드의 코스트, 다음 보스 기믹까지의 시간, 세 경우의 최종 시간과 현재 시각의 누적 피해를 한 줄로 확인합니다. 결과는 누적 피해, 생존, 행동·페이즈, 기록·버프 탭으로 나뉩니다. 누적 피해 그래프의 세로축은 1페이즈 HP와 최고 누적 피해 중 큰 쪽에 맞추며(전체 HP를 넘지 않음), 축이 전체 HP보다 작으면 제목 옆에 표시합니다.
5. 보스 패턴의 버튼 하나는 직접 배치 모드에서 **보스 패턴 추가**, 랜덤 예시 모드에서 **예시 다시 뽑기**로 바뀝니다.

지정 시각 방식과 코스트가 모이면 순서대로 사용하는 방식이 있습니다. 지정 시각의 반복은 설정한 간격으로 반복하며, 코스트가 부족한 반복은 적용하지 않습니다. 스킬 블록은 행동 시각과 피해 지연을 표시합니다. 강화 스킬, 명시적 상시 팀 서브 버프와 스페셜 지원 능력치는 자동 반영합니다. 주기가 명시된 기본 스킬과 스트라이커 일반 공격도 자동으로 진행합니다. 조건부 서브 스킬은 수동 행동으로 추가하고 필요한 지속 시간·조건 충족을 설정합니다.

설정은 현재 페이지 메모리에만 보관합니다. 학생을 오가도 각 육성 설정은 유지되며, 새로고침하면 초기화합니다. 성급과 레벨을 낮추어 잠긴 장비·무기·인연·잠재력도 입력은 보관하고 계산에서 제외합니다.

## 계산과 한계

자료는 [Schale DB](https://schaledb.com/)의 한국어 데이터입니다. 2026년 9월 28일 원본 빌드의 학생 277명(한국·글로벌 263명, 일본 전용 14명), 보스 14종, 종합전술시험 55회차와 공통 적 623개 항목을 포함합니다. 원본 서버별 출시 표시를 따르며 공식 출시 목록과 별도로 대조한 자료는 아닙니다. 대결전은 선택한 서버의 개최 이력이 있는 전장·방어 타입·난이도를 사용합니다. 아직 일본에도 출시되지 않은 학생은 원본에 계산 자료가 없어 추가하지 않습니다.

능력치는 원본의 레벨 보간·성급·장비·무기·인연·잠재력과 상한을 반영합니다. 장비는 최대 강화이며 인연은 해당 학생의 보너스만 사용합니다. 지원 능력치는 스페셜의 스킬 버프를 제외하고 체력/공격 10%, 방어/치유 5%씩 내림하여 스트라이커에 합산합니다. 버프는 능력치·스킬 슬롯·채널별로 적용하고 같은 슬롯/채널은 최근 효과가 덮어씁니다. 덮어쓴 버프는 새 효과가 만료되어도 복구하지 않습니다. 적용 프레임과 지속 시간을 구분합니다.

직접 피해는 상성·지형·레벨 차이·방어력·관통·명중·치명타·안정률·보스 피해 감소와 타격별 상한을 사용합니다. 서로 다른 대상이나 조건일 수 있는 여러 직접 피해 효과는 자동 합산하지 않고 행동마다 한 효과를 선택합니다. HP 의존·지속 피해·소환·축적·공격 변경·조건부 특수 코스트 변경 등 지원하지 않는 효과는 계산에서 제외하고 안내합니다. 단일 효과 계산기도 별도로 제공합니다.

택틱은 **0.1초 단위 단일 대상 HP 모델**입니다. 일반 공격 주기는 프레임을 이용한 추정이며 탄창과 재장전, 공격 속도 보정을 반영합니다. 기본 스킬 주기는 설명의 ‘초마다’ 값으로 추출하고 주기를 모르면 0으로 두어 자동 발동하지 않습니다. HitFrames가 있는 피해 효과는 원본의 각 타격 시각에 적용하고 그 시점의 버프·페이즈를 계산합니다. 없는 효과는 ApplyFrame 또는 스킬 Duration을 첫 피해 시점으로 사용합니다. 원본 타격 시점은 30프레임/초로 환산해 다음 0.1초 경계에서 처리하며, 수동 첫 피해 지연 보정도 가능합니다. 모든 팀원이 범위 버프 안에 있다고 가정합니다. 적 공격은 아래 방식으로 직접 배치합니다. 이동·엄폐·일반적인 변신/연속 EX와 보스 AI 시간표·복잡한 특수 기믹을 자동 재현하지 않습니다. 히나(드레스)의 집중 사격은 아래 규칙으로 별도 처리합니다.

- 평균: 안정률 균등분포, 치명타와 명중을 반영한 피해 기대값입니다.
- 운 좋은 경우: 독립 타격의 누적 평균 + 1.64485 × 표준편차를 사용하는 상위 5% 정규 근사입니다. 적은 타격 수, 조건 변화와 페이즈 전환에서는 실제 클리어 시간의 95% 분위수를 보장하지 않습니다.
- 이론 고점: 모두 명중하고, 발생 가능한 치명타와 최대 안정률이 나온 피해 상한입니다. 달성 확률을 의미하지 않습니다.

분포의 모멘트는 피해 상한의 구간별 선형식을 적분합니다. 모멘트 계산에서 정수 반올림은 생략하며 1회 피해 계산과 고점에서는 원래 반올림을 유지합니다. 무작위 표본을 반복 계산하지 않습니다. 팀 육성 자료와 지원 능력치는 업데이트마다 준비하고 전투 중 재사용합니다. 같은 전투 상태의 동일 효과 피해도 재사용합니다. 버프·디버프 적용과 만료, 사망, 페이즈 변경 시 컨텍스트와 피해 결과를 갱신합니다. 재생은 저장된 결과를 읽고 다시 시뮬레이션하지 않습니다. 단일 효과 계산기의 HitFrames 합계는 전 타격에 같은 입력 상태를 사용하며, 시간에 따른 변화는 택틱에서 계산합니다.

페이즈 HP는 원본 HP 전환점을 사용합니다. 시로&쿠로와 호버크래프트는 연속 보스, 카이텐은 레인저의 공유 HP와 로봇 HP를 구분합니다. 그 외 기믹 게이지·성배·분신·소환몹과 피해 전이는 자동 처리하지 않습니다. 페이즈 HP, 방어력, 추가 피해 배율, 전환 대기와 적 디버프 해제를 직접 조정할 수 있습니다. 전환 대기는 기본 0초입니다. 동일 적의 HP 전환에서는 초과 피해를 다음 구간으로 이어가며, 다른 적이나 대기 구간에는 이어가지 않습니다. 기본 보스 피해 감소는 유지합니다.

따라서 결과는 게임 기록의 실측 보증이 아닌 입력한 HP 모델의 추정입니다. 미지원 효과가 있는 팀은 일부 피해만 반영됩니다. 제한 시간 내 넘기지 못한 페이즈는 추정치를 외삽하지 않고 미완료로 표시합니다.

이미지는 Schale DB URL로 참조하며 로컬에 복제하지 않습니다. Google Fonts 연결 실패 시 시스템 글꼴을 사용합니다. 계산은 브라우저에서 실행하며 계정·DB·자동 폴링은 없습니다. 데이터는 학생과 보스 JSON 두 파일입니다.

## 갱신과 검증

```powershell
npm run data:update
npm test
```

갱신 스크립트는 Python 표준 라이브러리만 사용합니다. 원본 6개 자료를 가져와 검증하고 JSON 두 파일을 각각 원자적으로 교체합니다. 앱은 빌드 기준일이 다르면 로딩을 중단합니다. 자동 갱신은 하지 않습니다. 변경된 스키마는 브라우저 확인이 필요합니다.

테스트는 기본 능력치, 상성·방어·명중·치명·상한, 전체 학생의 유한 수치, 입력 보관, 지원 능력치, 버프 중첩·덮어쓰기·만료, 실제 보스 HP, 분포 모멘트, 코스트 회복과 사용 가능 시각, 페이즈 전환과 전투 경로 재현성을 확인합니다. 게임 클라이언트와의 실측 검증은 아닙니다.

Blue Archive 및 이미지의 권리는 원 권리자에게 있습니다. 비공식 개인 팬 도구입니다.


## 적 패턴과 생존

원본 적 623개 항목의 공격력·명중·치명·안정 수치와 179개 전투 스킬, 220개 보스 설명을 포함합니다. 기본 보스 모드는 실전 택틱 직접 배치입니다. 랜덤 예시는 별도로 선택하는 실험 모드입니다. 원본에는 AI 발동 확률·시간표가 없으므로, 실제 스킬 중 일반 공격을 제외한 패턴을 균등 선택하고 지정 간격의 ±20% 범위에서 발동합니다. 해당 패턴이 없는 적은 일반 공격을 사용합니다. 실제 AI 분포와 기본 공격 사이클을 재현하지 않습니다. 같은 보스의 HP 페이즈는 한 패턴 시간표를 공유하고 연속 보스는 활성 보스의 패턴만 실행합니다.
